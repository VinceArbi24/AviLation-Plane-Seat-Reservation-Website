# images/

Put the pictures your pages ask for here. Use these exact file names, because
the HTML already points to them.

| File               | Used on     | Notes                                                 |
|--------------------|-------------|-------------------------------------------------------|
| `airplane.png`     | index.html  | Hero picture. Transparent PNG, about 1000 x 1000 px   |
| `philippines.jpg`  | route.html  | Top of the Philippines card, about 800 x 600 px       |
| `asia.jpg`         | route.html  | Top of the Asia card                                  |
| `australia.jpg`    | route.html  | Top of the Australasia & Oceania card                 |
| `america.jpg`      | route.html  | Top of the Americas & Middle East card                |

Until the files are added, the pages show a plain coloured box with the alt text.
